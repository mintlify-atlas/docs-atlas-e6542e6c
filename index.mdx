Wisp for Plutonium is a full JavaScript implementation of the [Wisp protocol](https://github.com/MercuryWorkshop/wisp-protocol), providing both a browser-compatible client and a Node.js server. It multiplexes many TCP and UDP streams over a single WebSocket connection, enabling proxying scenarios that would otherwise require one WebSocket per destination. This build is customized and operated by Plutonium Network.

## What is Wisp?

Wisp is a lightweight binary protocol that lets a browser (or any WebSocket client) open multiple simultaneous TCP and UDP connections through a single WebSocket endpoint. Rather than requiring one WebSocket upgrade per destination host, all streams share one connection — reducing overhead and simplifying proxy infrastructure.
